# Beispieldaten

Alle Bausteine, Werte und Anforderungen sind **frei erfunden** (synthetisch). Sie stehen für das, was ein
Partner als Bausteinbeschreibung liefert: eine Datei je Baustein und Version, dazu der Anforderungsstand.
Bewusst eingebaut sind Fälle, die in echten Projekten vorkommen: eine Einheit ohne Gegenstück, eine informelle
Bedingung, eine Datei ohne Platz im Modell, eine Anforderung, die es im Anforderungsstand (noch) nicht gibt, und ein
Begriff, den der Wissensgraph nicht kennt.
